# DENCAL

一般病院の院内サーバー・PCでの動作を想定した電子カルテの試作です。機能を一つずつ実装しながら画面とデータ構造を調整します。

**実務利用前の試作です。架空データのみで確認してください。**

添付の画面コンポーネントを使い、外来カルテ診療、受付・会計算定、バックアップ・保存性、安全管理・監査証跡の4画面を用意しています。デモの職種切替では管理者 ＞ 医師 ＞ 看護師 ＞ 受付の順に下位の操作を継承します。

## 起動

Node.js 22以降と Python 3.10以降（SQLite 3.31以降）を使用します。

```sh
npm ci
npm run dev
npm run db:init
```

Viteが表示するローカルURLを開きます。`db:init` は新規SQLite DBを `data/dencal.sqlite3` に初期化します。別のファイルは `npm run db:init -- data/別名.sqlite3` で指定できます。

画面は添付由来の架空データで動きます。画面操作とSQLiteの接続は今後の実装です。画面の変更は再読み込みで消えます。電子署名、監査、会計、バックアップ、離席ロックの操作はデモです。

## マスターと外部連携

薬剤・傷病・診療行為・検査項目のマスターは別途取り込みます。デモの候補は架空データによる画面確認用です。

共通算定モジュールは利用しません。医療機関名義での契約・接続手続きが必要なため、試作段階では同モジュールとオンライン資格確認に接続していません。診療報酬の計算は将来、独自の算定機能と連携して行う設計です。画面の試算値は動作確認用です。
