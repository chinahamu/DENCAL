# DENCALと厚労省ガイドラインの対応表

基準日 2026年11月10日。一般病院の外来・入院で使う院内サーバー構成と院内PC単体構成を対象とする。開発段階では架空データで検証する。

この初版はDENCALに関係する主要項目の開発台帳で、原文の全遵守事項の判定表と病院全体の適合評価は導入構成が決まった時点で具体化する。実装・確認状況は各行に記載する。試作環境で確認した内容と対象病院での確認を区別する。対象リリースは未登録。

## 状態と担当の読み方

- **未実装**。製品機能や提供手順が計画段階。以後は「実装済・未確認」「確認済」を区別する。
- **院内確認待ち**。病院側の設定、体制、運用または委託先との合意を確認する項目。
- **適用判定待ち**。利用形態や対象文書に応じて判断する項目。「対象外」に更新する際は構成と根拠を記録する。
- **共同**。DENCAL側が機能や設定手順を用意し、導入先が設備・設定・運用を確認する。製品側の確認と院内確認は個別に記録する。

## 更新方法

1. 実装Issueの本文に表のIDと原文の章・遵守事項番号を記載する。複数の遵守事項を扱う行は、必要に応じて分割する。
2. 実装PRで対応行の状態と実装先を更新する。確認した際は、IssueまたはPR、確認日、対象コミットまたはリリース、確認した構成、結果・証跡を行に紐付ける。公開する証跡には架空データを用いる。
3. 実患者データを扱う前に、対象病院の構成で適用される原文の遵守事項、病院側の運用、条件付き項目を照合する。チェックリストとBCPの確認結果も病院側で保管する。

診療報酬の算定はRECEPTの担当。共通算定モジュールは利用せず、オンライン資格確認の本番連携は現時点で未実装。外部接続を追加する際は、対象システムと通信経路を明示し、関連行の適用判定を見直す。
