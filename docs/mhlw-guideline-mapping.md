# 厚生労働省ガイドライン第7.0版への対応表

- **確認日** 2026年11月11日
- **対象** DENCALの `main`（実装確認コミット [`1f681bb`](https://github.com/chinahamu/DENCAL/commit/1f681bb00191f93411a63296ad35169345854d69)）。架空データで動作を確認する、同一PC上の電子カルテ試作
- **参照資料** 厚生労働省「医療情報システムの安全管理に関するガイドライン 第7.0版」、[令和8年9月Q&A][qa]、令和8年6月のサイバーセキュリティ対策チェックリスト・BCP資料。[厚労省の公式資料一覧][mhlw]

**現状は実務利用前の試作です。** サーバーでSQLiteに保存する機能は職員認証・セッションと公式マスターです。診療・会計・監査・バックアップの画面操作はブラウザー内のデモで、変更は再読み込みで消えます。実環境の適合性は導入構成、運用、委託関係とその証跡を含めて評価する必要があります。実患者情報の取り扱いは想定していません。

## 要件と実装状況

「開発版で実装済み」は記載した範囲でサーバーまたはアプリが機能するもの、「一部実装」は不足があるもの、「画面デモ」は操作やテーブル定義の試作までのものです。章番号は特記のない限り[システム運用編][operation]を参照します。

## 検証の範囲
