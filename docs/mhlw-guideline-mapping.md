# 厚生労働省ガイドライン第7.0版への対応表

- **確認日** 2026年11月11日
- **対象** DENCALの `main`。架空データで動作を確認する、同一PC上の電子カルテ試作
- **参照資料** 厚生労働省「医療情報システムの安全管理に関するガイドライン 第7.0版」、[令和8年9月Q&A][qa]、令和8年6月のサイバーセキュリティ対策チェックリスト・BCP資料。[厚労省の公式資料一覧][mhlw]

**現状は実務利用前の試作です。** 職員認証・所属部署・セッション・公式マスター、診療録の下書き・確定版・訂正履歴をSQLiteに保存します。バックアップの操作は画面デモです。実環境の適合性は導入構成、運用、委託関係とその証跡を含めて評価する必要があります。実患者情報の取り扱いは想定していません。

## 要件と実装状況

「開発版で実装済み」は記載した範囲でサーバーまたはアプリが機能するもの、「一部実装」は不足があるもの、「画面デモ」は操作やテーブル定義の試作までのものです。章番号は特記のない限り[システム運用編][operation]を参照します。

## 検証の範囲

確認コマンドは `npm run lint`、`npm test`、`npm run build` です。[既存テスト](../src/utils/emrLogic.test.ts)は画面デモの職種階層、ハッシュ・照合ロジック、試算等を検証しています。[診療APIのテスト](../server/clinical.test.ts)は職種・部署によるアクセス制限と、旧DBの移行、再起動後の下書きと確定版、訂正理由、古い版による更新拒否、確定版の保護と改変検知に加え、検索と出力の権限、SQLiteを別ファイルへ復元した後の旧版・訂正版の表示を検証しています。実署名、障害復元、医療機関での受入は未検証です。
