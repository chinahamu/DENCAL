# PMDA電子添文から医薬品安全性情報を参照する（Step 1）

DENCALは医薬品マスターの薬価基準収載医薬品コード（YJコード）をキーに、**利用者がローカルで生成した**電子添文参照DBを読み込みます。この段階では、禁忌・併用禁忌・併用注意・重大な副作用・その他の副作用・患者背景への注意・重要な基本的注意・用法用量に関する注意の**表示のみ**を行います。自動的な処方可否判定は行いません。

## 1. PMDAから全件をダウンロードする

公式案内: https://www.pmda.go.jp/safety/info-services/medi-navi/0012.html

操作ヘルプ: https://push.info.pmda.go.jp/mypage/view/mypage/mypageHelp.html

1. PMDAメディナビに登録し、**マイ医薬品集作成サービス**にログインします。利用に登録が必要です。
2. マイ医薬品集の登録医薬品一覧から **「一括ダウンロード」** を押します。
3. 利用規約を確認し、同意します。
4. ダウンロード対象は **「全医療用医薬品添付文書」** を指定します。**「マイ医薬品集に登録済み」に限定しない**でください。
5. ファイル形式は **「SGML/XMLのみ」** を選択します。PDFも別途保管したい場合は「PDF/SGML/XML」を選択できますが、本ツールの解析対象はXMLです。
6. 生成したダウンロードファイルを取得・展開します。例: `/private/pmda_all/SGML_XML/製品名/xxxx.xml`。**ファイル名は変更しない**でください。
7. 初回は全件を取得し、以降はPMDA側の期間指定による更新分も確認してください。DENCALのこの版は現時点では増分マージをせず、**手元の全件フォルダを更新したうえで、DB全体を再生成**します。

> PMDAが提供する一括ダウンロード機能は公式の利用規約に従って操作してください。DENCALがPMDAに自動ログイン・巡回する機能はありません。

## 2. ローカルSQLiteを生成する

DENCALのリポジトリで以下を実行します（Python 3.10以降）。

```sh
python3 tools/import_pmda.py "/private/pmda_all/SGML_XML" --output data/pmda-safety.sqlite3
```

Windowsでは、実際に同期・解凍したローカルパスを指定してください。

```powershell
py -3 tools/import_pmda.py "C:\\pmda_all\\SGML_XML" --output data/pmda-safety.sqlite3
```

- **Google Driveの共有URLをコマンドに指定しても処理できません**。実ファイルをローカルにダウンロード・同期してください。
- サブフォルダを再帰走査して `*.xml` を読みます。旧様式の `*.sgm` はこの版では対象外です。PDFは解析しません。
- 1添文に複数製品のYJコードがあれば、同一添文に複数の製品を対応付けます。
- XMLに `YJCode` がないもの、形式が異なるもの等はエラー一覧に記録します。名称だけのあいまいな自動照合はしません。
- 実行結果の `errors` と `imported_documents` を必ず確認してください。**取り込み成功数は全薬剤の網羅や安全性の保証ではありません**。
- 作成先には一時SQLiteを使い、最低1件は成功して整合性検証が通った場合のみ置換します。成功したものとエラーのあるものが混在するときは、エラー一覧を確認してください。
- 出力は機密性を考慮して権限を限定し、バックアップと更新履歴を管理してください。

デフォルトでは `data/pmda-safety.sqlite3` を読みます。別の場所で管理する場合はサーバー起動時に `DENCAL_PMDA_DB` 環境変数でSQLiteのパスを指定します。

```sh
DENCAL_PMDA_DB=/private/safety/pmda-safety.sqlite3 npm run dev
```

## 3. DENCALで参照する

1. 先に厚生労働省の **医薬品マスター（y_YYYYMMDD.csv）** をDENCALの「マスター管理」に取り込みます。
2. 医師・管理者で「外来カルテ診療」の「処方オーダ」を開き、医薬品マスターから薬剤を選びます。
3. 選択した薬剤の **医薬品安全性情報** を展開して確認できます。すでに登録した処方薬の「安全性情報」ボタンからも確認できます。
4. 表示にはYJコード、添文ID、改訂年月、取込日、元ファイル名、SHA-256の一部を付します。常にPMDA公式サイトで最新版を照合してください。
5. **「抽出データなし」「対応添文なし」「安全性DB未取込」は『禁忌なし』『安全』ではありません。**

処方の可否、薬剤相互作用、患者背景との突き合わせは**未実装**です。自動判定や医学的な最終確認に利用しないでください。自由記述の薬剤群、脚注、図表、参照関係の解釈は電子添文原本と差が生じ得ます。

## 4. 配布・権利と安全管理

- GitHubで公開するのは **パーサー、SQLiteスキーマ、API、画面表示コード、人工テストデータ** のみです。
- PMDAから取得した電子添文XML・PDF・画像や、それらの本文を収録した生成済みSQLiteは **DENCALのリポジトリ・リリースに同梱しません**。
- 利用者は利用規約に従い公式サイトから取得し、自己の管理する環境で参照DBを生成します。XMLの院内機械処理の利用範囲は、利用施設でも最新のPMDA規約を確認してください。
- `data/` と `*.sqlite3` は `.gitignore` で除外しています。ローカル生成物を公開リポジトリへPUSHしないでください。
- 原本の更新や安全性速報は、ローカルDBに直ちに反映されるわけではありません。臨床での使用可否を保証するものではありません。

## 5. 動作確認

```sh
python3 tools/import_pmda.test.py
npm run lint
npm run build
```

実データでの確認例：ワーファリンの添文は1文書に複数YJコードがあり、相互作用は相手薬剤名と措置・機序を組として表示します。その他の副作用は `categoryRef` / `frequencyRef` を解決して区分・頻度の対応を保持します。
